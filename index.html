Respeite prefers-reduced-motion. Não crie animações novas sem usar o mesmo easing.

Acessibilidade

  • Foco visível: focus-visible:ring-2 focus-visible:ring-pv-green-500
  • Labels: aria-label em botões de ícone, aria-pressed em toggles, aria-expanded em menus, aria-disabled em itens desabilitados
  • Contraste: branco sobre #223f99 e pv-blue-900 (AA); selo amarelo usa pv-blue-950 no texto
  • Semântica: landmarks nav/main/footer corretos
  • Reduced motion: animações decorativas respeitam a preferência do sistema

Anti-padrões (não fazer)

  1. Não usar font-press-start fora do logotipo.
  2. Não usar hex solto de cor — sempre token pv-*.
  3. Não criar sombra com preto puro — usar a família rgba(15,35,56,…).
  4. Não inventar raio novo — usar os valores da seção de raios.
  5. Não criar CSS local por serviço para o que já tem token ou componente.
  6. Não usar slate para cor de marca — marca é sempre pv-*.
  7. Não quebrar o grid de cards (1/2/3 colunas) sem motivo.

Pendências / dívidas

  • #223f99 (azul do herói, footer e logotipo) é usado como hex solto e não tem token. Criar pv-blue-* e migrar.
  • slate-* é usado para bordas de card e inputs; decidir se vira token ou permanece como neutro utilitário.
  • Cada serviço em src/servicos/* tem .css próprio; migrar para tokens e componentes gradualmente.
  • Tokens shadcn (--color-primary etc.) só funcionam dentro de .calc-root; se o portal adotar shadcn globalmente, redefinir.
