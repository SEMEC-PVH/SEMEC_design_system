Adiciona receitas de Button, Input, Select, Textarea, FormField, Card, Alert, Header, ErrorSummary, Badge e Toast para aplicações sem React. A skill lite e o campo `classes` dos manifests passam a oferecer classes extraídas dos componentes, variantes, HTML acessível e CSS puro gerado com os tokens do kit. A skill completa referencia essas anatomias.
